# REQ-01 Requisitos del modulo de devoluciones (v1.0)

Estado: aprobado. Fecha: 2026-03-02.

- R1. El plazo de devolucion es de 14 dias naturales desde la entrega.
- R2. Los productos de la categoria `perecedero` no admiten devolucion.
- R3. El reembolso se realiza por el mismo medio de pago utilizado en la compra.
- R4. Las devoluciones de importe superior a 300 EUR requieren aprobacion de un supervisor.
- R5. El cliente debe recibir un correo de confirmacion en un maximo de 24 horas.
