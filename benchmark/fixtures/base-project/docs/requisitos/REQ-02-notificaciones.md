# REQ-02 Requisitos de notificaciones (v1.3)

Estado: aprobado. Fecha: 2026-04-11.

- N1. Todas las notificaciones al cliente se envian por correo electronico.
- N2. Las notificaciones de devolucion se envian tambien por SMS si el cliente lo ha autorizado.
- N3. El tiempo maximo de envio de cualquier confirmacion es de 12 horas.
  Este requisito prevalece sobre cualquier plazo de confirmacion definido en documentos anteriores.
- N4. Los mensajes se redactan en el idioma configurado en el perfil del cliente.
